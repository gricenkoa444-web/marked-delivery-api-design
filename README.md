# Проектирование API приёмки маркированной поставки

## Описание

Учебный проект: проектирование API метода «Подтвердить приёмку поставки»
для внешней системы учёта. Показывает, как описать вызов, обязательные
поля, ошибки и безопасный повтор запроса при сбое сети.
Все данные вымышлены, реальные системы и рабочие материалы не используются.

**Статус:** черновик, спецификация в работе.

## Процесс, который описывается

Поставщик отгружает маркированный товар и отправляет электронный документ.
Склад физически принимает товар, сканирует коды маркировки и сверяет
количество с документом. После проверки приёмка подтверждается в системе
учёта. Проект описывает последний шаг: вызов подтверждения.
